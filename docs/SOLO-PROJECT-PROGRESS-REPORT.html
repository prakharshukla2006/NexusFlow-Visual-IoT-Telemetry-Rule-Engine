📌 1. Project Abstract & Solo Architecture Overview

NexusFlow is an end-to-end web-based Industrial Internet of Things (IIoT) platform designed to ingest high-frequency telemetry from industrial equipment (gas turbines, compressors, pumps, generators), evaluate user-configurable rules in real time, and trigger responsive alerts (webhooks, SMS) and live SCADA visualizations.

As the sole developer, I am implementing all four architectural tiers of the application across the 4-week development plan:

  • Frontend SCADA Visualization Tier: React 18, Vite, TypeScript, Tailwind CSS, and Recharts with synchronized multi-sensor monitoring.
  • High-Frequency Ingestion & Communication Tier: Node.js, Express, and RFC 6455 WebSocket gateway delivering sub-second updates.
  • Visual Workflow Canvas & Stream Processing Tier: React Flow node-based editor compiling into reactive RxJS Observable pipelines.
  • Time-Series Persistence & Alert Integration Tier: MongoDB Time Series storage, HTTP outbound webhooks, and mock SMS dispatchers.
