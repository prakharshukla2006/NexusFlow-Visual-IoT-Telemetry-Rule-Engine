💡 3. Important Topics & Viva Defense Answers (Evaluator Q&A)

Q1 Why must the visual rule graph be a Directed Acyclic Graph (DAG)?

Answer: Industrial telemetry is a unidirectional time-series stream (Source → Average → Threshold → Action). If a user connects an edge from a downstream filter back into an upstream node, it introduces a circular feedback cycle. In reactive stream processing, this causes infinite recursion loops, buffer blowouts, and server failure. Enforcing the DAG invariant guarantees deterministic, finite execution and zero deadlocks.

Q2 How does Kahn's Algorithm detect cycles and compute execution order?

Answer: Kahn's algorithm operates on in-degrees (incoming edges per node): (1) Compute in-degree for all vertices; (2) Enqueue nodes with in-degree 0 (data sources); (3) Dequeue each node, record it in topological order, and decrement the in-degree of its neighbor nodes; (4) If a neighbor's in-degree drops to 0, enqueue it; (5) If total visited nodes equals graph size |V|, the graph is a valid DAG with exact execution order [src → ma → thresh → alert]; if visited < |V|, a feedback cycle exists and the graph is rejected (O(V+E) complexity).

Q3 Why use a Moving Average instead of evaluating raw sensor readings directly?

Answer: Physical industrial sensors encounter transient electromagnetic noise and mechanical jitter. An isolated 5ms spike of 95°C should not trigger a factory-wide turbine shutdown. A Simple Moving Average (SMA = 1/N · Σ x(t-i)) acts as a low-pass filter, smoothing transient noise and ensuring alarms fire only on sustained, genuine thermal or vibration excursions.

Q4 Why treat the visual graph as JSON configuration rather than generating executable code?

Answer: Treating visual graphs as declarative JSON configuration prevents arbitrary code execution and sandbox escapes (avoiding eval/new Function). JSON can be saved safely in MongoDB, validated against strict schemas, version-controlled, and audited without exposing the server runtime to injected malicious scripts.
